# 판단부 (AI 에이전트)

거리·각도를 받아 다음 행동을 결정. 제안서의 "AI 드론 에이전트"가 맡는 자리.

## 인터페이스

```python
def decide(state) -> action
```

```python
tools = [approach, align, touch, retry_search]
state = "거리 87cm, 각도 12도, 최근 3프레임 중 1번 검출 실패"
```

## 두 가지 구현

| 파일 | 용도 |
|---|---|
| `rule_based.py` | 발표 실시간 시연용 — 네트워크 의존 없음 |
| `llm_based.py` | 개념 증명용 — function calling |

인터페이스가 같으므로 교체만으로 전환된다.

## 왜 LLM이 모터를 직접 조종하지 않는가

- **지연** — 호출에 1~3초. 실시간 제어(수십 Hz)엔 못 씀
- **불안정** — 같은 상황에 다른 값을 뱉음. 정밀 정렬 부적합
- **위험** — 응답 하나가 잘못되면 드론이 즉시 이상하게 움직임

LLM은 **"무엇을"** 만 정하고, **"어떻게"** 는 검증된 제어 코드가 맡는다.
