# 위치 계산부

카메라 영상에서 거리와 각도를 **숫자로** 만드는 부분.

## 인터페이스

```python
def get_pose() -> (distance, angle)
```

이 시그니처는 고정. 내부 구현만 교체한다.

## 구간별 방식

```
3m ───────────────── 0.5m ──────── 접촉
  【 이동 구간 】            【 정렬 구간 】
  Depth  또는  단안 다중뷰      RGB + PnP
     ↑ 방식 2개 중 선택          ↑ 대안 없음, 고정
```

**이동 구간** — 두 방식 중 선택
- Depth: D435i가 거리를 직접 준다. 계산 없음
- 단안 다중뷰: 두 프레임 시차로 삼각측량. 스케일 보정 필요

**정렬 구간** — RGB + PnP 고정
- depth는 최소 측정 거리와 화면 반사 문제 (한계선은 실측으로 확정할 것)
- 단안 다중뷰는 정지 상태라 시차가 없어 원리상 불가

## 주의

마커 크기 상수는 `sim/generate_marker.py`와 **반드시 일치**해야 한다.
불일치 시 거리 추정에 체계적 편향이 생기고, 에러 없이 조용히 틀린다.
(85mm 가정 오류로 +34% 편향을 겪은 적 있음)
